## 中文摘要

**病例概要：** 皮疹与激素治疗后发生DKA，长期胰岛素依赖促使原作者改称暴发1型。已核对表2，但后续C肽不能代替初发分型标准；药物致病机制未证实。

**学习目标：**

- 从三项证据识别DKA。
- 区分急症处理与糖尿病分型。
- 制定防复发教育重点。
- 说明抗体暴露和C肽检测时点的解释局限。

**关键决策：** 糖尿病酮症酸中毒，需要先处理代谢急症再判断分型；核对胰岛功能与糖尿病分型，落实胰岛素、血糖/酮体监测和病日教育；表2支持后续胰岛分泌下降，不能替代初发标准；IAA在用胰岛素后测得，分型需专科复核。

**复盘要点：** 先识别DKA，不因激素暴露忽略酸中毒。 出院教育必须覆盖监测及避免自行中断必要胰岛素。 时间关联不等于药物免疫致病证据。

原报告结局：一年余后中断胰岛素再发DKA，IAA和ICA阳性、GAD65阴性。表2第一次检查0/120 min C肽0.3/0.5 nmol/L，血糖5.5/23.8 mmol/L；第二次0/120 min C肽0.1/0.2 nmol/L，血糖7.5/20.2 mmol/L。两表为后续检查，不能替代初发时值。之后持续胰岛素依赖、体重下降20 kg、血糖波动，作者修正为暴发1型糖尿病；当前仅可保留这一原诊断并标明标准无法完全复现。
