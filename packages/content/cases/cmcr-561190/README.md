## 中文摘要

**病例概要：** 原报告临床诊断重症EGPA伴急进性肾炎表型和心肌损伤；缺乏组织证实，随访仍残留肾损害。

**学习目标：**

- 识别嗜酸细胞增多合并急进性肾炎。
- 比较血管炎与嗜酸细胞综合征。
- 识别肾脏与心脏急症的优先级。
- 说明病理未证实与残留肾损害。

**关键决策：** ANCA相关血管炎伴重度嗜酸细胞增多，原报告临床判断EGPA，组织机制未证实；紧急肾脏支持并由风湿、肾脏和心脏团队评估诱导治疗与感染风险；可脱离透析但仍有肾功能损害，不能宣称新月体病理或冠脉炎已被证实。

**复盘要点：** 阴性单基因检测不能排除全部嗜酸细胞综合征。 严重EGPA需器官支持与专科诱导治疗评估。 临床诊断应与未证实的组织机制分开。

原报告结局：血液滤过/透析及激素、环磷酰胺后嗜酸细胞下降、尿量恢复并脱离透析，心电及胸部影像改善。出院肌酐401 μmol/L，一年余随访244–273 μmol/L，ANCA阴性。
