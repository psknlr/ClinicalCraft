## 中文摘要

**病例概要：** 剖宫产后大肠埃希菌坏死性筋膜炎伴感染性休克，白细胞减少不能排除重症，关键是及时外科源控制。

**学习目标：**

- 识别产后坏死性软组织感染。
- 解释低白细胞不能排除重症。
- 确定早期外科源控制优先级。
- 复盘延误和长期重建负担。

**关键决策：** 迅速扩大的疼痛瘀斑、水疱、全身毒性与筋膜坏死支持坏死性软组织感染；立即外科会诊和复苏，尽早源控制并给予合适广谱抗感染；不说明；原文承认约第5天才确诊清创偏晚，长期重建不能验证延误。

**复盘要点：** 按病情危险程度行动，不依赖白细胞升高。 皮肤改变可能低估深部筋膜受累。 历史抢救中的药物组合不是今天的通用方案。

原报告结局：原报告清创后仍发生广泛皮肤和肌肉坏死，经历多次清创、植皮和皮瓣重建，共住院403天，最终治愈出院。作者明确反思发病约5天后才确诊并清创偏晚。
