## 中文摘要

**病例概要：** 拔除中心导管后脑空气栓塞，有明确 CT 证据；栓塞具体路径仍为推测。

**学习目标：**

- 识别拔管后神经急变与 CT 气体的关联。
- 提出立即防进气与氧合支持。
- 说明高压氧团队紧急参与的理由。
- 区分反常与逆行静脉路径的不确定性。

**关键决策：** 导管拔除相关脑空气栓塞；阻止进一步进气、气道氧合和循环支持，并紧急联系高压氧及神经重症团队；提示反常栓塞可能，但不能排除逆行静脉等路径。

**复盘要点：** 气密封闭和安全拔管流程具有预防意义。 急性神经气体栓塞需紧急氧合及专科评估。 结构性分流线索不等于已拍到栓塞路径。

原报告结局：接受呼吸支持、高压氧和康复；次日清醒但左侧重瘫，逐步改善，约 35 天能独立行走。未给更长随访。
