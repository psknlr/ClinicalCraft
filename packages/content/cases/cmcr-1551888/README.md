## 中文摘要

**病例概要：** 旧三尖瓣生物瓣重度梗阻，原团队再次置换后短期恢复。

**学习目标：**

- 识别生物瓣梗阻与症状的一致性。
- 说明正常范围附近的左室射血分数不能排除右心瓣膜病。
- 提出个体化再干预风险评估。
- 区分单例可行性与长期比较疗效。

**关键决策：** 症状性三尖瓣生物瓣功能障碍；心脏团队核对瓣膜机制与手术风险后个体化再干预；只证明本例可行，不能推断长期优越性。

**复盘要点：** 射血分数不能代替瓣膜与右心评估。 复杂再干预需心脏团队评估（ESC/EACTS 2025）。 短期康复与长期安全性分开。

原报告结局：原团队采用胸腔镜辅助再次置换，体外循环 182 分钟；术后第 2 天拔管，第 3 天转普通病房，第 13 天出院。长期随访未提供。
