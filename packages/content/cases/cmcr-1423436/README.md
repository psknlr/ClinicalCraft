**学习目标：**

- 整合痛、胰酶与影像识别胰腺炎。
- 系统评价药物及其他病因。
- 区别现代支持原则与历史多药方案。

**复盘要点：** 诊断胰腺炎与确定病因是两步。 NICE NG104 不建议预防性抗菌或无理由禁食。 不以危险再激发替代因果评估。
