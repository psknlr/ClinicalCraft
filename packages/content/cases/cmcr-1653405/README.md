- Review PET/CT: Multiple heterogeneous FDG-avid hepatic lesions, SUVmax 7.1; largest about 11.2×10.6×7.9 cm with low central uptake, interpreted as malignancy with intratumoural bleeding and intrahepatic spread.
- Review the existing liver biopsy: Right hepatic mass biopsy was diagnosed as angiosarcoma; individual immunostains are not supplied.

## 中文摘要

**病例概要：** 病理确诊肝血管肉瘤，伴影像出血线索，后续发生致死性肝内出血。

**学习目标：**

- 区分影像恶性提示与组织学确诊。
- 解释正常 AFP 的局限性。
- 识别肝血管性肿瘤的出血安全问题。
- 谨慎表达穿刺与后续出血的因果关系。

**关键决策：** 既有组织病理支持肝血管肉瘤；肝胆、肿瘤及介入团队评估出血和组织证据，避免未经风险评估的重复穿刺；后续出血的精确机制不能由现有资料归咎于穿刺。

**复盘要点：** PET 摄取不是组织学特异诊断。 影像、病理和出血风险须同时考虑（原病例）。 时间先后不自动构成穿刺致死的因果证据。
