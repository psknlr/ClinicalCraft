## 中文摘要

**病例概要：** 造影后严重迟发皮肤黏膜反应，碘克沙醇为可疑药物，但多药暴露与分型缺失需保留。

**学习目标：**

- 识别严重皮肤黏膜反应警示。
- 构建多药及造影剂时间线。
- 平衡皮肤风险与心脏停药风险。
- 避免危险再激发与泛化“碘过敏”。

**关键决策：** 黏膜破溃、进食困难与水疱提示严重皮肤反应风险；紧急皮肤/过敏团队评估黏膜、眼及全身受累，与心脏团队平衡停药风险；记录具体碘克沙醇疑似严重迟发反应，避免自行再激发并专科评估替代。

**复盘要点：** 黏膜和水疱是升级信号。 ESUR 2025 强调按反应表型记录及后续专科评估。 不要把旧文“激素不足”解释当作已证实唯一原因。
