## 中文摘要

**病例概要：** 报告诊断难治性儿童混合结缔组织病；指端坏死及肺线索要求持续器官和安全评估。

**学习目标：** 以多器官及nRNP证据解释混合结缔组织病方向；辨认原发雷诺不能解释的组织损伤；指出正文与表1的CK、HBDH及RF不一致；制定兼顾缺血和免疫治疗安全的专科计划

**关键决策：** 哪种解释更能覆盖临床与抗体结果？ 后续资料能支持哪一项结论？ 对难治性病程和生物制剂应如何决策？

**复盘要点：** 多器官表现比单一抗体更重要；正常CRP不能否定严重指端病变；治疗前后变化不能确立单项疗法的因果效果。尚待核对：体重、完整感染筛查、CK参考范围、长期肺功能和远期生物制剂安全性。本稿尚未经执业医师审核。
