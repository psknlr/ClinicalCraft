## 中文摘要

**病例概要：** 报告诊断儿童原发性血小板增多症，需避免将血小板数或单一变异当作全部风险判断。

**学习目标：** 比较反应性与克隆性血小板增多的证据；说明骨髓及分子证据的增量价值；指出极高血小板时出血仍可能重要；评估血栓和出血双重风险，不照搬历史儿童药物剂量

**关键决策：** 持续极高血小板应怎样鉴别？ 后续资料能支持哪一项结论？ 如何权衡预防血栓与治疗出血风险？

**复盘要点：** 比较反应性与克隆性血小板增多的证据；说明骨髓及分子证据的增量价值；指出极高血小板时出血仍可能重要。尚待核对：VWF功能、儿童专科现行诊断复核、惊厥机制及长期转归。本稿尚未经执业医师审核。
