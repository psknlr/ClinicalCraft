## 中文摘要

**病例概要：** 肝硬化急性失代偿并低血糖、脑病和肾损害，后证实MRSA菌血症与腹水感染；初始腹水PMN未达经典SBP阈值。

**学习目标：**

- 识别肝病意识障碍中的低血糖威胁。
- 准确解释腹水PMN180/μl。
- 将感染评估纳入急性失代偿。
- 区分事后培养信息与初始决策。

**关键决策：** 考虑肝性脑病并同时处理低血糖、感染及器官功能恶化；不能按经典≥250阈值直接确诊SBP，但重症感染线索仍需及时经验治疗与培养评估；血与腹水同检出MRSA支持侵袭性感染，需考虑初始抗菌谱不足，但不能证明单一改药必能救治。

**复盘要点：** 意识障碍需同步寻找低血糖与感染。 区分腹水细胞计数阈值与有症状菌腹水。 培养时间决定当时可用证据。

原报告结局：原报告给予多项肝病支持和头孢曲松等治疗，意识迅速恶化，入院4小时后死亡。死后血与腹水培养均鉴定MRSA，多重耐药，对万古霉素、利奈唑胺敏感。
