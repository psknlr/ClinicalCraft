## 中文摘要

**病例概要：** 导管相关胸腹水造成呼吸恶化；原报告称乳糜胸，但直接机制和现代脂质确证不足。

**学习目标：**

- 识别置管后呼吸恶化的机械性线索。
- 整合胸腹影像与胸水结果。
- 提出新生儿团队安全处理与通路评估。
- 明确乳糜胸及导管损伤证据边界。

**关键决策：** 导管相关胸水/外渗或淋巴损伤，原报告诊断乳糜胸；新生儿团队立即评估呼吸循环、积液及可疑导管并规划安全引流/替代通路；保留原报告名称，但无脂质/乳糜微粒数据不能确证全部机制。

**复盘要点：** 置管后的新变化需重新评估导管。 病例引流量不能作为通用处方。 诊断标签与确证证据分开。

原报告结局：原报告胸穿、拔 PICC 后胸水及腹水消退，转回 CPAP，住院 54 天体重 2.4 kg 出院；2、4 个月随访生长发育报告正常。

审核状态：已核对原报告，尚未完成现行指南与执业医师审核。所有检查均为病历查阅；未载明的体检、数值及治疗反应保持未知。
