## 中文摘要

**病例概要：** 肌注与过度抗凝共同构成血肿风险，止血后仍需重新规划瓣膜抗栓。

**学习目标：**

- 识别抗凝相关注射血肿。
- 整合 Hb、INR 与局部影像。
- 兼顾止血与瓣膜血栓风险。
- 区分时间关联与输血并发症确证。

**关键决策：** 抗凝过度背景下肌注相关血肿；暂缓华法林并紧急评估止血/逆转需要，联合瓣膜团队规划安全恢复；需要复评容量和心功能；低 INR 也需结合瓣膜抗栓目标，而非越低越安全。

**复盘要点：** 给药途径必须考虑抗凝状态。 ACC 2020 强调严重出血评估及按风险恢复抗凝。 原文高剂量逆转不能成为通用处方。

原报告结局：逆转后引流发现血凝块而非脓液；术后 Hb 降至 58 g/L，输血后出现胸闷气短并被考虑心衰，治疗后缓解。后来恢复华法林，1 个月瘀斑消退、INR 2.1。
