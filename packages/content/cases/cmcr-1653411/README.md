## 中文摘要

**病例概要：** 持续缺血伴 RBBB 和动态心电图改变，后续证实前降支近段严重闭塞。

**学习目标：**

- 识别 RBBB 背景下的动态缺血信号。
- 整合胸痛与标志物确定处理紧迫性。
- 避免把不典型 ST 形态作为排除依据。
- 说明基线缺失限制新发 RBBB 判断。

**关键决策：** 高度怀疑持续心肌缺血，RBBB 不构成放心等待的依据；立即升级心脏团队评估急诊再灌注；RBBB 是否新发及确切梗死范围尚不能由现有资料确定。

**复盘要点：** 连续心电图应与症状变化一起解释。 高度疑似持续缺血合并 RBBB 需紧急评估（ESC 2023）。 单例不能证明延迟与全部损伤的定量因果。

原报告结局：症状反复后急诊造影显示前降支近段次全闭塞并置入支架；术后 1 周心电图仍为 RBBB，V2–V4 QS、V5 rS，原文称广泛梗死图形。远期结局未载。
