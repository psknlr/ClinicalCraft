## 中文摘要

**病例概要：** 阿德福韦相关近端小管障碍与低磷、行走异常相伴；改善支持关联而非全部机制确证。

**学习目标：**

- 识别正常血糖性尿糖和小管蛋白尿。
- 将低磷与长期药物暴露关联。
- 提出兼顾肝肾安全的换药评估。
- 区分去激发支持与神经机制确证。

**关键决策：** 近端小管多种重吸收障碍，考虑阿德福韦相关 Fanconi 综合征；肝病与肾脏团队调整可疑抗病毒药，同时维持 HBV 控制并监测小管指标；支持药物关联，但脊髓及周围神经的独立致病机制未证明。

**复盘要点：** 肌酐不能替代近端小管指标。 说明书列有 Fanconi 与低磷风险。 换药时兼顾乙肝持续控制。

原报告结局：原报告换为恩替卡韦并补充相关营养/骨代谢治疗，数周磷改善；5 个月后恢复正常行走，尿小管指标明显下降，但部分仍异常。
