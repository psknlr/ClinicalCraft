## 中文摘要

**病例概要：** 临床与 MECP2 检测共同支持 Rett 综合征，需持续多学科照护。

**学习目标：**

- 识别发育异常与刻板手动作的诊断价值。
- 整合 MECP2 与临床表型。
- 区分历史支持治疗与当前专科选择。
- 提供保留检测边界的遗传解释。

**关键决策：** 表型与 MECP2 变异支持 Rett 综合征；神经、遗传与康复团队评估功能、并发症及当前可用治疗；父母该位点阴性支持散发可能，但不等于排除所有复发风险。

**复盘要点：** 刻板动作不等于癫痫。 FDA 2023 已批准 trofinetide；是否适用及可及性需专科核对，不能照搬旧治疗观。 父母单个位点阴性不是零遗传风险证明。

原报告结局：原报告给予维生素 B6 并建议康复；家属在家进行手活动、音乐与交流训练，6 个月随访无明显加重，未证明疾病逆转。
